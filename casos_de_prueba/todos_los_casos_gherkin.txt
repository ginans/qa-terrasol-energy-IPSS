# HU01: NAVEGACIÓN INTUITIVA
# ------------------------------------------------------------------------------
Característica: HU01 - Navegación Intuitiva en TerraSol Parcelas
  Como usuario potencial de parcelas
  Quiero disponer de un menú de navegación funcional y accesible en todas las páginas
  Para explorar los detalles y disponibilidad de los terrenos sin obstáculos

  Criterio de Aceptación 1.1:
  El menú de navegación debe permitir el acceso directo a la sección de parcelas desde la página de inicio.

  Escenario: CP-TS-01 - Navegación exitosa a la sección de parcelas desde el menú principal
    Dado que el usuario se encuentra en la página de inicio "https://clinicatecnologica.cl/terrasol/index.html"
    Cuando hace clic en el enlace "Parcelas" del menú de navegación superior
    Entonces el navegador debe redirigir a la URL "https://clinicatecnologica.cl/terrasol/parcelas.html"
    Y la página debe mostrar el título "Parcelas" y el catálogo de lotes disponibles

  Criterio de Aceptación 1.2:
  Todos los enlaces del menú de navegación en páginas secundarias deben apuntar a rutas válidas y existentes.

  Escenario: CP-TS-02 - Verificación de enlace de navegación a parcelas desde la página FAQ
    Dado que el usuario se encuentra en la página de preguntas frecuentes "https://clinicatecnologica.cl/terrasol/faq.html"
    Cuando hace clic en el enlace "Parcelas" situado en la barra de navegación superior
    Entonces el sistema debe dirigir al usuario a la página existente "parcelas.html" con código HTTP 200
    Y no debe mostrar un mensaje de error HTTP 404 "Not Found"

# HU06: NAVEGACIÓN SEGURA
# ------------------------------------------------------------------------------
Característica: HU06 - Navegación Segura y Protección de Datos Personales en TerraSol
  Como usuario que entrega información personal y de contacto
  Quiero que la transmisión de mis datos se realice mediante canales cifrados y métodos seguros
  Para garantizar la confidencialidad de mi información frente a terceros no autorizados

  Criterio de Aceptación 6.1:
  La navegación y recursos del sitio deben servirse exclusivamente bajo protocolo cifrado HTTPS.

  Escenario: CP-TS-11 - Verificación de certificado TLS/HTTPS en toda la navegación
    Dado que el usuario ingresa al dominio "https://clinicatecnologica.cl/terrasol/"
    Cuando verifica la conexión en la barra de direcciones del navegador
    Entonces la conexión debe indicar un candado de seguridad activo con protocolo HTTPS
    Y el certificado digital debe ser válido y emitido por una entidad certificadora reconocida

  Criterio de Aceptación 6.2:
  Los datos personales del formulario deben transmitirse mediante método seguro HTTP POST y no por GET.

  Escenario: CP-TS-12 - Transmisión confidencial de datos personales (Evitar CWE-598)
    Dado que el usuario completa el formulario de contacto con sus datos personales (nombre, teléfono, correo)
    Cuando presiona el botón "Enviar solicitud"
    Entonces la petición HTTP hacia el servidor debe realizarse mediante el método "POST"
    Y los datos personales sensibles no deben ser expuestos como parámetros de consulta en la URL (Query String)
